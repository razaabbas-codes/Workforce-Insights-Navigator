🧭 Workforce Insights Navigator (Single-File Scrollytelling)

This is a modern, interactive HR analytics dashboard built entirely using HTML, CSS (inline styling), and D3.js for visualization. It presents key Human Resources data through a "scrollytelling" format, guiding the user through several steps of analysis, from executive KPIs to detailed workforce distribution charts and client data tables.

Description: A streamlined, single-page HR dashboard that provides executive and detailed insights into workforce distribution, new hire trends, and key client metrics via D3.js data visualizations.

Because the entire application is contained within a single index.html file, it is extremely easy to deploy and share.

✨ Features

Single-File Simplicity: All code (HTML, CSS, JavaScript, D3 logic) is contained in one file, simplifying deployment.

D3.js Visualizations: Uses the D3 library to render dynamic and responsive charts (Bar Charts, Donut Chart, Line Chart).

Scrollytelling Format: Presents data analysis in a narrative, slide-by-slide format, focusing the user's attention.

Real-time Clock: Displays the current date and time in the header for a dynamic dashboard feel.

Simulated Data: Uses randomized data generation logic within the JavaScript to create realistic HR metrics (Departments, Locations, Joiners, etc.).

Interactive Table: Includes a fully sortable HTML table for detailed client and manager data.

🚀 How to Run Locally

Since this project is pure front-end HTML and JavaScript, you do not need any special servers or build tools to run it.

Save the File: Ensure the code is saved as a single file, typically named index.html or hr_analytics_dashboard_2d.html.

Open in Browser: Double-click the saved file. It will open directly in your default web browser (Chrome, Firefox, Edge, etc.).

💻 Technical Stack

HTML5: Structure and content.

CSS (Inline/<style>): Custom styling for a dark, professional aesthetic.

JavaScript (Vanilla): Core logic for dashboard interaction, scrolling, and data generation.

D3.js (v7): Used extensively for data binding, scaling, axis generation, and rendering all SVG charts.

📦 Deployment via GitHub Pages

This project is perfectly suited for deployment using GitHub Pages, which allows you to turn your GitHub repository into a live website for free.
